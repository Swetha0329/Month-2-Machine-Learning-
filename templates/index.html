↻ Learning from feedback

The 👍 and 👎 buttons on each result are saved to feedback.csv. Retrain the model with them whenever you like.

  1. Collect corrections using the feedback buttons on the Analyze tab.
  2. Stop the app, then run python retrain.py in the project folder.
  3. The script compares the new model with the old one and only saves it if it is not worse.
  4. Start the app again to use the retrained model.

⌘ REST API

Use MailGuard from other apps, scripts, or a browser extension. All responses are JSON.

Endpoints

POST/api/predictClassify one message, or up to 50 with "messages"
POST/api/feedbackReport whether a prediction was correct
GET/api/statsLive usage counts
GET/api/compareAlgorithm comparison results
GET/api/healthCheck that the service is running

cURL example

curl -X POST http://127.0.0.1:5000/api/predict \ -H "Content-Type: application/json" \ -d '{"message": "You have won a FREE prize! Click to claim."}'

Python example

import requests response = requests.post( "http://127.0.0.1:5000/api/predict", json={"message": "You have won a FREE prize! Click to claim."}, ) print(response.json()["prediction"])

Example response

{ "prediction": "Spam", "is_spam": true, "confidence": 99.1, "threat": { "score": 62, "level": "High" }, "suspicious_words": [ { "word": "free", "count": 1 } ], "links": [], "explanation": { "toward_spam": [ { "word": "claim", "weight": 0.4376 } ], "toward_ham": [] } }
